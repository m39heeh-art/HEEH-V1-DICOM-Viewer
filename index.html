About HEEH-V1

HEEH-V1 is an open-source medical imaging research and education platform. It integrates image review, calibrated measurements, quantitative imaging, radiomics-oriented outputs, experimental AI tools, and provenance-aware export within a single workflow.

  • DICOM and NIfTI image review
  • Volumetric visualization
  • Calibrated measurements
  • Quantitative imaging analysis
  • Radiomics-oriented outputs
  • Experimental AI tools
  • Provenance-aware export

Workflow Overview

HEEH-V1 supports a reproducible workflow from medical image input to quantitative analysis and structured export.

Application Interface

The HEEH-V1 interface is designed for medical image review, calibrated measurements, and reproducible quantitative analysis.

Provenance-Aware Export

HEEH-V1 supports structured export and documentation of image sources, processing steps, and analysis outputs to support reproducible research.
