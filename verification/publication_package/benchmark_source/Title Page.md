## Data Availability Statement
Public metadata provenance for the TCIA/NBIA collection CT-Phantom4Radiomics is reported exactly. The full archive was not downloaded in this environment; therefore, the benchmark statements are limited to metadata-level provenance, synthetic phantom measurements, a matched PyRadiomics comparison on a synthetic ROI, verification against the official IBSI Configuration D reference values (CT radiomics phantom), generated challenge fixtures, and the fixed runtime workload. All machine-readable benchmark artifacts are included in the project repository (`verification/results/`, mirrored in the submission's evidence package).
